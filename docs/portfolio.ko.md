# 포트폴리오 목표

[English](portfolio.md) | [한국어](portfolio.ko.md)

저장소 자체를 포트폴리오로 사용합니다. 계획, 진행 현황, 코드, 사례, 설계 결정, 측정 결과를 한곳에 둡니다. 실제 근거가 생겼을 때 항목을 추가합니다.

## 목표 산출물

- [ ] 문제, 입출력 예시, 재현 가능한 빠른 실행 방법이 있는 README
- [ ] 변경 분석부터 보고서까지 실행되는 CLI 첫 버전
- [ ] 고정된 Git ref를 가진 정상 변경·주입 결함 사례
- [ ] 테스트 선정 근거, 로그, 생성 테스트 결과, 잔여 위험이 담긴 QA 보고서 예시
- [ ] LangChain, RAG, LangGraph, MCP, API 도입 시점과 이유를 설명하는 설계 결정
- [ ] 검출·누락 결함, 테스트 품질, 실행 시간, 모델 비용, 검토 시간의 평가 결과
- [ ] 실패 사례와 솔직한 한계
- [ ] 한국어 번역본으로 연결되는 영문 기본 문서
- [ ] 다른 개발자가 공개 자료로 재현할 수 있는 데모

## 완성된 포트폴리오가 답할 질문

1. 규칙만으로 자동화하기 어려웠던 판단은 무엇인가?
2. 모델의 오류를 어떻게 발견하거나 제한하는가?
3. 어떤 결함을 검출하거나 놓쳤으며 측정 조건은 무엇인가?
4. 어떤 아키텍처 선택이 도움이 됐고 비용은 무엇인가?

측정하지 않은 목표를 달성 결과로 쓰지 않습니다. 공개 토이 앱과 합성 사례만 사용합니다.
